# Dashboard de Vendas Xbox

## Descrição do Projeto

Este projeto foi desenvolvido como parte de um desafio de criação de dashboard em Excel, com foco na organização, análise e visualização de dados de vendas.

O objetivo principal foi transformar uma base de dados bruta em um painel visual claro, interativo e útil para análise do desempenho de vendas da Xbox, permitindo uma melhor tomada de decisão com base em dados.

## Objetivo

Criar um dashboard de vendas no Excel com foco em:

* Organização dos dados
* Criação de perguntas de negócio
* Construção de tabelas dinâmicas
* Desenvolvimento de gráficos
* Criação de indicadores visuais
* Apresentação dos dados de forma clara e profissional

## Dados Utilizados

A base de dados contém informações relacionadas a assinaturas Xbox, incluindo:

* ID do assinante
* Tipo de assinatura
* Plano contratado
* Valor total da venda
* Renovação automática
* Produtos adicionais, como EA Play e Minecraft Season Pass

## Perguntas de Negócio

Durante o desenvolvimento do projeto, foram definidas perguntas que poderiam ser feitas por uma diretoria comercial, como:

1. Qual foi o faturamento total?
2. Qual modalidade de assinatura gera mais receita?
3. Qual plano gera mais receita?
4. Qual percentual dos clientes utiliza renovação automática?

## Indicadores Criados

O dashboard apresenta os seguintes indicadores:

* Faturamento total
* Receita por modalidade de assinatura
* Receita por plano
* Percentual de clientes com renovação automática

## Dashboard

O painel foi desenvolvido com uma identidade visual inspirada na marca Xbox, utilizando tons de verde, cards visuais e gráficos para facilitar a interpretação dos dados.

## Como Reproduzir

Para reproduzir este projeto:

1. Baixe o arquivo `dashboard_vendas_xbox.xlsx`
2. Abra o arquivo no Microsoft Excel
3. Acesse a aba `Dashboard`
4. Utilize os filtros disponíveis para interagir com os dados
5. Caso altere a base de dados, atualize as tabelas dinâmicas em `Dados > Atualizar Tudo`

## Estrutura do Arquivo Excel

O arquivo contém as seguintes abas principais:

* `Bases`: contém os dados brutos utilizados na análise
* `Cálculos`: contém as tabelas dinâmicas e perguntas de negócio
* `Dashboard`: contém o painel visual final
* `Assets`: contém elementos visuais, cores e apoio ao layout

## Conclusão

Este projeto demonstra a aplicação de conceitos de análise de dados no Excel, desde a organização da base até a criação de um dashboard visual e interativo.

O resultado final permite acompanhar o desempenho das vendas, identificar os produtos e planos com maior faturamento e analisar a retenção de clientes por meio da renovação automática.
